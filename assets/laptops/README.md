# Laptop photos

Add product photos in this folder when you have them. The app looks for a filename made from the laptop model in lowercase, with spaces and punctuation replaced by hyphens.

For example, a model named `Lenovo LOQ 15` can use any of:

- `lenovo-loq-15.jpg`
- `lenovo-loq-15.png`
- `lenovo-loq-15.webp`

Supported formats: JPG, JPEG, PNG, and WebP. Until a photo is added, the app displays a matching laptop illustration placeholder.
